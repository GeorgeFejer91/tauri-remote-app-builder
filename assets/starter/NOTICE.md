# Starter notice

This reusable starter combines material adapted from
`GeorgeFejer91/tauri-browser-remote-control` at commit
`0fbf222da89469c63844e8b49fcb6d0047431b74` with newly authored CLI adapter
material from `GeorgeFejer91/tauri-remote-app-builder`.

It is MIT licensed; retain the adjacent `LICENSE` file when copying or
redistributing substantial portions.

The starter deliberately does not include a production authentication
implementation, signaling credentials, public endpoint, platform-specific
local IPC, or a claim that generated applications are secure or production
ready. Product dependencies and assets require their own license review.
